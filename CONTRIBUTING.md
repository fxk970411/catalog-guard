# Contributing

Start with an issue describing a real catalog failure and a minimal fictional fixture. Do not upload personal data, credentials, commercial datasets, or data you lack permission to share.

Run `python3 -m unittest discover -s tests -v`. For a bug fix, add a regression test that fails before the fix. Keep the runtime dependency-free where practical. Changes to rules or report shape need documentation and compatibility notes. Examples must remain fictional.

Maintainers review behavior, tests, privacy and scope before merging. AI-assisted contributions are welcome; the contributor must understand and review the changes. Never invent test results, users, endorsements or benchmarks. Be respectful and focus feedback on the work.

Suggested first contributions: a real-world CSV edge-case fixture, clearer translations, or a documented integration. Features in the roadmap are proposals, not promises. No response-time guarantee is currently offered.
